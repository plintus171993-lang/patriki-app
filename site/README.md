# Сайт «Патрики Паб» — веселый-патрик.рф

Статический сайт (HTML + JS без сборки) на той же базе Supabase, что и приложение patriki-app.

- Меню, доставка с оплатой, бронь стола, вход по номеру телефона (Telegram-бот / звонок), карта гостя с QR — та же логика, что в приложении (`js/store.js`, `js/loyalty.js`, `js/config.js`, `js/seed.js` — копии из `patriki-app/www/js`; при изменениях там — скопировать сюда).
- Новости, акции и афиша — таблица `news`, правятся в админке приложения → вкладка «Сайт».
- Заявки на мероприятия (день рождения, корпоратив, свадьба, банкет, аренда зала) — `submit_event_request`, приходят в Telegram-чат паба и владельца, видны в админке → «Сайт».
- Документы (политика, оферта, согласие) — на https://patrikipab.ru/legal/.
