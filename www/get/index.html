Патрики Паб

Доставка из паба: Петроградская сторона и Мурино

iPhone
  1. Нажмите «Открыть приложение» ниже — откроется в Safari.
  2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
  3. Выберите «На экран “Домой”» → «Добавить».
Иконка с бульдогом появится на экране, как обычное приложение. Открыть приложение
Android Скачать приложение (APK) Телефон может спросить разрешение на установку из браузера — нажмите «Настройки» → «Разрешить», затем «Установить». Или открыть без установки
Откройте эту страницу с телефона — отсканируйте QR-код в пабе. Или пользуйтесь веб-версией прямо здесь. Открыть приложение
